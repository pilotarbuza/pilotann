# План развития ANN

[ [English](ROADMAP.md) | Русский ]

Что ANN умеет сейчас и что будет дальше.

## Сейчас: версия 1.2, работает в продакшене

Поиск запущен и работает в Telegram-боте и веб-приложении.

Что уже есть:

- Гибридный поиск: SQLite FTS5 (BM25) и LanceDB (`multilingual-e5-base`), результаты объединяются по алгоритму RRF.
- Ответ в два шага: Claude Haiku быстро пишет черновик, Claude Sonnet проверяет цитаты и ограничения.
- Страницы PDF: `pypdfium2` рисует страницу, нужное предложение подсвечивается.
- Типы ВС: Airbus (A220–A380), Boeing (737–787), Superjet 100, ATR 42/72, Embraer, CRJ, Dash 8, L-410, Cessna, Diamond.
- Погода: декодер METAR и TAF с расчетом бокового ветра по каждой полосе.
- SimBrief: загрузка плана полета (OFP) и разбор навигационного расчета.
- Telegram Mini App и PWA на `ann.pilotarbuza.com`, вход через Telegram, Google, Apple или почту.
- Нормативка: поиск по ФАП РФ (128, 293, 10, 147).

## Ближайшие планы (Q1–Q2 2027)

### Документация и типы ВС

- [ ] Полные Normal и Non-Normal Checklists (QRH) с пошаговым ведением пилота.
- [ ] Поддержка MEL: бот сам посчитает, можно ли отложить устранение дефекта (Rectification Interval Categories A, B, C, D).
- [ ] Нормальная нарезка таблиц летно-технических характеристик (Takeoff/Landing Distance, Engine Out climb gradients).

### Mini App и PWA

- [ ] Карта полета: запасные аэродромы вдоль маршрута SimBrief, раскрашенные по погоде (VFR, MVFR, IFR, LIFR).
- [ ] Самые нужные чеклисты будут доступны офлайн через IndexedDB и Service Worker.
- [ ] Закладки и история запросов, общие для бота и веба.

## Дальше (Q3–Q4 2027)

### Голосовой ввод

- [ ] Распознавание речи на Whisper, дообученном на фразеологии радиообмена (ICAO Doc 9432 и ФАП).
- [ ] Можно будет спросить голосом (*«Внуково погода полоса 19 ветер»*) и сразу получить ответ голосом или текстом.

### Поиск без интернета

- [ ] Пробуем запускать легкие модели эмбеддингов прямо в браузере пилота через ONNX Runtime Web / WebAssembly, чтобы поиск работал на эшелоне без связи.
